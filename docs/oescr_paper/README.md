# OESCRの理論・実装と数値検証

全32ページ、数式30件、図5点（計算フロー1点・ベンチマーク4組）、参考文献12件。

OESCRを用いて、プラズマ状態から発光を予測し、複数の観測から温度・密度を推定する方法を論文形式で説明する。背景から方程式、機能群、数値実装、検証結果、実測への展開へと読み進められる構成とした。

[閲覧用PDF](../../output/pdf/oescr_theory_and_validation_ja.pdf) / [原稿・図・根拠データの一式](../../output/oescr_paper_bundle.zip)

## 本文の構成

1. 低圧プラズマ診断における位置づけ
2. 電子衝突と準位収支
3. 固有発光から測定スペクトルへの変換
4. 推定目的、測定誤差、識別可能性
5. 物理項の改訂と複数ガスへの展開
6. **機能群の連携、計算フローと数値実装**：固定構造と反復評価、率積分、画素積分、共通校正誤差、最終診断をフロー図と数式で説明
7. ベンチマークの設定、結果、診断設計への示唆
8. **実測への展開と拡張課題**：実装済み機能、次の検証段階、計算核の拡張を表で整理

本稿の実装・数値は2026年10月27日に保存したソースを対象とする。解析解との比較と生成回復で計算経路を検証し、校正済み実測と独立診断による精度評価を次の科学的作業に位置づける。Ar/Cl₂の回復判定FAILも、観測感度と改善候補を示す結果として掲載した。

## 再組版とフロー図

XeLaTeX互換環境またはTectonicを使用する。`manuscript/`を作業ディレクトリとして `tectonic main.tex` を実行する。このリポジトリでは、`reproduce/build_pdf.ps1 -Compiler <tectonicの実行パス>` が所定のPDF出力先まで生成する。

日本語・欧文にはYu Mincho、Yu Gothic、Times New Roman、Arial、Consolasを使用する。他の環境では、原稿のフォント指定を利用可能なフォントへ変更する。閲覧用PDFにはフォントとベクトル図を埋め込んでいる。

第6章のフロー図は、リポジトリルートから `python docs/oescr_paper/reproduce/make_computation_flow.py` で再生成できる。ベンチマーク図と数値の再計算は[根拠データの説明](evidence/README.md)に従う。
