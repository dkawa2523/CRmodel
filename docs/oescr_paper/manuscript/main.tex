\begin{abstract}
低圧・非平衡プラズマの発光強度は、観測対象の粒子密度に加え、電子エネルギー分布、準安定状態からの段階励起、放射分岐、衝突消光、光学系の応答に依存する。このため、線強度を直接プラズマ状態へ読み替えるには、励起動力学と観測過程を明示したモデルが必要である。本稿では、研究用PythonコードOESCRの保存した実装スナップショットを対象に、エネルギー分布からの速度係数積分、定常線形の縮約衝突放射方程式、視線積分、装置応答および重み付き逆解析を一つの測定方程式として記述する。物理項の追加・置換、複数ガスの合成、測定共分散と局所識別可能性の扱いを実装に対応づける。再実行した生成データの検証では、Ar/O$_2$の共有温度・密度を良好に回復する一方、Ar/Cl$_2$では小さいスペクトル残差と密度の回復誤差が併存する。六励起kernelのAr例は、五kernelによる温度推定と別上準位の予測確認を通して、広帯域の入力から推定までの処理を確認する。これらは数値的一貫性の検証であり、独立実測に対する温度・密度精度の検証ではない。OESCRの有用性は、仮定を変更した際のスペクトルへの影響を追跡し、与えられた観測がどの状態量を制約できるかを検討できる点にある。
\end{abstract}
